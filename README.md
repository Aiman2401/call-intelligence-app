# Call Intelligence Tool

## Deployed URL
https://call-intelligence-app.onrender.com

## One-command setup
cd backend && pip install -r requirements.txt && uvicorn main:app --reload

## Stack
- Backend: FastAPI (Python)
- Database: SQLite
- LLM: Gemini 2.5 Flash
